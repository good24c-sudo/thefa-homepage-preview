상미의 확장 개발 · 개발 중 · 시안 1.2

내 얼굴의 분위기부터, 오늘의 약속 코디까지.

상미 2.0은 기존 상미의 뷰티·그루밍을 바탕으로, 관상에서 찾은 스타일 포인트에 평소 취향, 계절, 약속 상황을 더해 옷·신발·액세서리·화장까지 오늘의 코디를 완성하는 확장 시안입니다.

이 페이지는 개발 중인 상미 2.0 시안 1.2를 미리 보여드립니다. 실제 얼굴 분석·날씨·로그인·구매는 연결하지 않았고, 사진은 기존 상미의 가상 모델 이미지입니다.

한 흐름으로 이어지는 스타일 큐레이션

계절에 맞는 옷을 먼저 고르고, 내가 고른 분위기와 약속 상황을 더해 코디 3가지 조합을 보여주는 시안입니다. 신발이나 화장만 따로 바꿔볼 수도 있습니다.

사진만으로 사람을 단정하는 대신, 사용자가 알고 있는 정보와 오늘의 상황을 함께 씁니다. 새로 사기 전에 이미 가진 옷을 잘 활용하도록 돕는 방향입니다.

옷은 계절에 맞게 날씨는 신발·겉옷 세부 조정 분위기 4가지 중 선택 코디 3가지 조합

시안에서 이해할 것

  • 관상 표현은 화장·헤어·액세서리 같은 스타일 포인트 설명입니다. 의료 진단·성격·운명 판정이 아닙니다.
  • 날씨는 사용자가 골라 보는 검토용 가정이며, 기상청 실시간 연동이나 위치 자동 수집이 아닙니다.
  • 코디 품목·색상은 규칙 기반 구성 예시이며, 실제 상품 검색·가격·재고·판매 연결이 아닙니다.
  • 사진 속 인물과 착장은 가상 모델 이미지이며, 실제 이용자 사진이나 판매 상품이 아닙니다.

하나의 분위기, 전체 스타일로

화장·옷·신발·액세서리를 한 흐름으로 살펴보는 스타일 보드입니다. 기능 소개용 가상 이미지이며, 실제 추천 착장은 아닙니다.

빠르게 추천받기

“토요일 저녁 동창회가 있어.” 약속 한 문장으로 시작하면 계절과 고른 분위기로 코디를 구성해요.

더 상세한 큐레이션

착용감·평소 사이즈·예산·이미 가진 옷까지 더해 나에게 한 걸음 더 맞춰요.

시안 1.2 화면 둘러보기

화면을 누르면 크게 볼 수 있습니다. 모든 화면은 개발 중인 시안이며 실제 서비스와 분리되어 있습니다.

‘상미 토탈 스타일’은 가제입니다. 상미 2.0은 별도 출시 제품이 아닌 상미의 확장 개발이며, 이 페이지는 시안 1.2를 담은 개발 중 미리보기입니다.
